Đăng nhập CMS

Dùng tài khoản quản trị để thay ảnh website ngay lập tức.

Tài khoản nhân viên:
  • Tài khoản: admin
  • Mật khẩu: hoang-cung-2026

Quản lý Hình ảnh

  1. Đăng nhập bằng tài khoản admin.
  2. Vào mục Quản lý Hình ảnh.
  3. Tìm ảnh cần thay đổi.
  4. Bấm Thay thế → chọn ảnh mới → bấm Upload.
  5. Ảnh trên website cập nhật ngay lập tức.
