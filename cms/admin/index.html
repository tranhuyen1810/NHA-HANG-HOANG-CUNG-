CMS Nhà Hàng Hoàng Cung

  1. Đăng nhập bằng tài khoản admin.

  4. Bấm Thay thế → chọn ảnh mới → bấm Upload.

Chỉnh sửa nội dung hiển thị trên website. Nhấn Lưu để cập nhật từng mục.
